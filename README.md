# ZEERAK SHAHZAD | Cybersecurity Portfolio

A modern, premium portfolio website showcasing cybersecurity expertise, certifications, and projects.

## Features

- 🔒 **SOC Operations** - Experience with Splunk, Wazuh SIEM
- 🛡️ **ISO 27001 Lead Auditor** - Certified compliance expertise
- 🎯 **Security Automation** - Python scripting & automation
- 🔐 **Penetration Testing** - Offensive security skills

## Tech Stack

- React + Vite
- Framer Motion (animations)
- Tailwind CSS
- Lucide Icons

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Deployment

Deploy easily on:
- **Vercel** - Just import from GitHub
- **Netlify** - Connect your repo
- **GitHub Pages** - Use the build output
